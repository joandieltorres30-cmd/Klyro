Klyro classic UI + games build.
This version keeps the original Klyro sidebar/home/chat/settings/admin design.
Game thumbnails are stored at the repo root so GitHub mobile uploads that flatten the folder still work.
Playable browser games include Snake, 2048, Reaction Test, Typing Race, Aim Trainer, Memory Test, Connect 4, Tic Tac Toe, Brick Breaker and Clicker Factory.
Other games are listed with a ready game window.
